Regras operacionais

  • Perguntas pessoais simples devem ser respondidas em até 3 segundos.
  • Insegurança, consulta a documento ou ajuda de terceiros devem ser consideradas resposta incorreta.
  • A confirmação deve ser realizada pelo titular.
  • Para última compra, considerar a última autorização aprovada.
  • Transação negada pode ser considerada quando os detalhes informados forem compatíveis.
  • A compra deve estar entre os últimos 3 meses. Caso seja mais antiga, substitua por pergunta obrigatória.
  • Resposta “não sei” ou “não tenho acesso” deve ser considerada incorreta.
  • A tolerância de valor é de R$ 5,00 para mais ou para menos.
  • É permitida uma única substituição por categoria.
